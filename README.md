Odoo 19 自定义模块 `aging_report` 的独立展示站。与 Odoo 系统本身完全分离：**不修改、不依赖、不启动 Odoo 也能打开**。

## 在线试用（核心功能）

页面顶部的 `#try` 区块是可操作的账龄分析台，不是截图：

- **数据导入**：Excel `.xlsx / .xlsm / .xls`（SheetJS）与 `.csv / .txt`（UTF-8 / GBK、分隔符探测）；支持按钮选择和拖拽；根据表头里的「客户 / 应收 / 销售」或「供应商 / 应付 / 采购」自动判断应收或应付，也可手动切换。
- **表头与清洗**：在文件前 10 行内自动探测表头，支持中英文同义词（客户名称、供应商、往来单位、到期日、付款到期日等）；跳过空行、合计行与零余额行；日期支持日期对象、`YYYY-MM-DD`、`YYYY/MM/DD` 和 Excel 序列号；金额去除 `,`、`¥`、括号负数等。
- **到期日与账龄**：缺到期日时按单据日期 + 30 天推算；按截止日计算逾期天数，分为「未到期 / 0–30 / 30–60 / 60–90 / 90+」五段。
- **风险分级**：未逾期或余额 ≤ 0 为正常；余额 ≥ 大额阈值（默认 ¥100,000）为高风险；逾期超过 90 天或余额 ≥ 阈值一半为关注；其余正常。
- **看板与清单**：5 个指标（行数、应收 / 应付余额、逾期余额、逾期率、高风险行）、五段账龄条形图、高风险 / 关注 / 正常三档构成，以及按风险等级排序的明细清单。
- **筛选与导出**：按风险筛选、按往来单位 / 单据号搜索；可导出全部明细 CSV（UTF-8 BOM），并下载当前报表类型的 CSV 导入模板。
- **两个内置样例**：应收 63 行、应付 48 行，打开页面默认载入应收；样例按钮会把截止日与大额阈值恢复到演示基线 `2026-10-19 / ¥100,000`，保证文档中的数字可复现。
- **数据边界**：解析与分析全部在浏览器本地完成，不上传、不写入 Odoo；关闭页面后不保留导入的业务数据。

内置样例的汇总结果已与项目自身的 Python `parser.py` + `compute_aging` 逐项核对：

| 样例 | 行数 | 余额 | 逾期余额 | 逾期率 | 高风险 | 关注 | 正常 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 应收 | 63 | ¥8,130,770 | ¥5,663,170 | 69.65% | 20 / ¥3,731,100 | 21 | 22 |
| 应付 | 48 | ¥5,344,330 | ¥3,759,330 | 70.34% | 18 / ¥2,626,155 | 14 | 16 |

## 中英双语

右上角 `中文 / EN` 切换。选择会写入 `localStorage`，下次打开保持；隐私模式下写入失败会自动忽略，不影响页面。

实现方式：所有文案成对写在 `.zh` / `.en` 中，由 `html[data-lang]` 控制显隐；标题、`<h1>`、表格、按钮、图表说明均已覆盖。

## 部署

纯静态文件，当前已通过 GitHub Pages 从 `main` 分支根目录发布。也可以直接放到任意静态托管（Nginx、Cloudflare Pages、对象存储）；保持 `index.html` 与 `assets\` 的相对路径不变即可。

Excel 链接使用 `download` 属性；在 `file://` 下浏览器可能改为直接预览或另存，均属正常行为。

## 设计

按 IBM Carbon Design System 实现：

- IBM Blue `#0f62fe`、ink `#161616`、canvas `#ffffff`、surface `#f4f4f4`、hairline `#e0e0e0`
- 直角、无阴影、1px 分隔线；正文 16px / 字距 0.16px；展示标题 300 字重
- IBM Plex Sans / Plex Sans SC / Plex Mono
- 深色仅用于页脚，整体为单一浅色视觉世界（设计上有意为之）

风险色沿用系统语义：高风险 `#da1e28`，关注 `#f1c21b`（文字用深琥珀以保证对比度）。

## 真实性边界

本站展示的是 **Odoo 19 上的个人实践项目**，用于验证应收应付账龄分析的实施思路：

- 不是生产部署，也没有真实客户项目或真实业务数据；
- 往来单位、金额、发票号与日期均为合成数据；
- 在线试用是解析与账龄逻辑的浏览器移植版，用于演示与自查，不是 Odoo 服务端本身；
- 开发过程为 Vibe Coding（AI 辅助编码）；
- 指标（111 行、¥13,475,100、69.93%、38 笔高风险）均来自样例数据的实际计算结果，并经独立重算核对。

演示地址 `http://127.0.0.1:8069/web/login?db=practice` 与 `admin / admin` 仅适用于本机演示环境。
